# 기사 프로젝트 노트

기사 한 건을 진행하면서 쓰는 한 장짜리 노트 페이지입니다. HTML 파일 하나로 되어 있고, 별도 설치나 서버 없이 브라우저에서 바로 열립니다.

## 구성

| 칸 | 설명 |
| --- | --- |
| 프로젝트 한 줄 | 프로젝트를 한 줄로 적는 칸 |
| 주제 | 대주제 **경제** |
| 할 일 체크리스트 | 5개 칸. 내용을 쓰고 체크하면 취소선이 표시됩니다 |
| 날짜별 기록 | 11/18부터 하루 한 줄. "+ 다음 날 추가"로 날짜가 늘어납니다 |

- 휴대폰 화면에서도 보기 좋게 만든 반응형 레이아웃입니다.
- 페이지가 열릴 때와 체크·입력·기록 추가 때 가벼운 애니메이션이 나옵니다. 기기에서 "동작 줄이기"를 켜 두면 애니메이션은 꺼집니다.
- 전화번호나 주소 같은 개인정보 칸은 없습니다.

## 사용 방법

1. `article-project-note.html` 파일을 브라우저에서 엽니다.
2. 칸을 눌러 내용을 입력합니다.

입력한 내용은 사용하는 브라우저(`localStorage`)에 자동으로 저장되어 다시 열어도 남아 있습니다.

## 알아둘 점

- 저장된 내용은 **그 기기, 그 브라우저에서만** 보입니다. 다른 기기나 다른 사람과는 공유되지 않습니다.
- 웹에 공개해도 방문자는 각자 빈 노트를 보게 됩니다. 내가 쓴 내용이 다른 사람에게 보이지 않습니다.
- 브라우저의 사이트 데이터를 지우면 저장된 내용도 함께 지워집니다.

## GitHub Pages로 공개하기

1. 저장소의 `main` 브랜치에 HTML 파일을 올립니다.
2. 홈페이지로 보이게 하려면 파일 이름을 `index.html`로 바꿉니다.
3. 저장소의 **Settings → Pages**에서 게시할 브랜치를 선택하면 주소가 만들어집니다.

## 파일

```
├── article-project-note.html   # 노트 페이지 (HTML 하나로 완결)
└── README.md
```
